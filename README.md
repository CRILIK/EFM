# Эпичные схватки · помощник Crilik

Мобильный фанатский помощник для двух настольных игр:

- **Крутагидон — Экстремально острый чипсихоз:** каталог из 245 физических карт (134 разных записи), фото всех 134 разновидностей карт, быстрые покупки, раздача стартовой руки, журнал, сравнение фамильяров и свойств, пошаговая стратегия по доступным данным.
- **Месиво на грибучем болоте:** каталог 94 разновидностей карт с фото, подбор заклинаний, учёт карт, жизней и вероятностей могучего броска.

Сайт работает без серверной части и без регистрации. Данные партии хранятся в браузере данного устройства, по запросу экспортируются в JSON. Это **не гарантия победы**: в настольной игре есть случайности и неизвестная рука соперников. Часть сложных эффектов нужно применять вручную по картам.

## Запуск

1. Скачайте ZIP этого проекта и распакуйте всю папку.
2. Откройте `index.html` в браузере вместе с папкой `assets`. Для локальной проверки можно запустить из папки проекта `python -m http.server 8000`, затем открыть `http://localhost:8000`. Фотографии должны находиться в `assets/images/cards/`.
3. На Android откройте адрес GitHub Pages через Chrome, затем нажмите круглую кнопку **⬇** в правом нижнем углу сайта. Там можно установить приложение (при поддержке браузером) и отдельно сохранить все 230 изображений карт (~9 МБ) для игры без интернета. Если кнопку установки не предлагают, используйте меню браузера → **Добавить на главный экран**.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub. Для **GitHub Free** публикация через Pages доступна из публичного репозитория. Перед публикацией фотографий карт убедитесь, что у вас есть право распространять изображения; иначе используйте проект локально и не делайте его общедоступным.
2. Загрузите **содержимое папки проекта** (файл `index.html` должен лежать в корне репозитория, не внутри дополнительной папки).
3. В репозитории выберите **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.
4. После публикации сайт обычно доступен по адресу `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`. Не вписывайте этот URL заранее: GitHub покажет точную ссылку в Pages.

На GitHub Pages опубликованный сайт, включая изображения карт, **публично доступен** даже при частном репозитории на планах, где это поддерживается. Обратите внимание на права правообладателей иллюстраций. Фотографии карт предоставлены пользователем; автор проекта не утверждает, что имеет право распространять чужие рисунки. При необходимости замените картинки своими разрешёнными материалами или используйте проект только локально.

## Структура

- `index.html` — весь игровой интерфейс (включая встроенную вторую игру)
- `assets/css/game.css` — внешний стиль в эстетике карточной игры
- `assets/js/card-gallery.js` — сопоставление названий с фотографиями
- `assets/images/cards/*.webp` — оптимизированные фото игровых карт
- `assets/data/krutagidon-catalog.json` — база карточек со свойствами
- `assets/data/photo-map.json` — пути к фото
- `manifest.webmanifest`, `sw.js`, `assets/js/pwa.js` — установка на телефон и отдельная загрузка всех 230 фотографий в офлайн-кэш на HTTPS (только по нажатию)
- `tests/` — браузерные и логические автотесты, включая проверку офлайн-пакета

### Изменения в каталоге и сохранение

Для переноса партий используйте экспорт JSON в журнале приложения и затем импорт на новом устройстве. При обновлении сайта браузер может не перенести данные из локального HTML: делайте резервную копию. JSON базы карт — вспомогательный файл для обновлений разработчиком и **не нужен игроку для запуска**.

### Правила и примечания

Старт каждого игрока в «Чипсихозе»: **6 Знаков + 1 Сырная палочка + 3 Пшика**, первая рука **5 карт**. Жетон **«Усиленная палочка»** меняет один Знак на Палочку-хреналочку до перемешивания. Фамильяр не добавляется в стартовую руку. Алгоритм учитывает известные эффекты, но обращайтесь к бумажным правилам при любых спорных ситуациях.

Источник правил: https://hobbygames.ru/download/rules/ESBM_Krutagidon_Chipsihoz_Pravila.pdf

**Статус изображений:** ко всем 134 разновидностям карт «Крутагидона» и 94 разновидностям карт «Грибучего болота» привязаны фотографии; у части снимков есть фон стола или края соседних карт. Они служат визуальными подсказками и не являются сканами издательского качества.


## Проверка качества по принципам UB Mode

Проект проверяется по принципу «сначала работает — затем корректно — затем регрессионные тесты».
В `tests/` лежат: `test_site.py` (мобильный/настольный интерфейс, раздача,
каталог, стратегия, переключение игр), `test_abilities.py` (замена начального
Знака выбранным свойством), `test_integrity.py` (полнота каталога, пути к
фотографиям, синтаксис JS, манифест PWA), `test_delivery.py` (проверка мобильного экрана, 178/178 карт и диалога офлайна), `test_pwa_cache.js` (модель загрузки всех фото в кэш). Запуск после установки Playwright:

```bash
python -m pip install playwright
python tests/test_integrity.py
python tests/test_site.py
python tests/test_abilities.py
python tests/test_delivery.py
node tests/test_pwa_cache.js
```

Тесты браузера используют Chromium и ввод HTML прямо в DOM, поскольку в
изолированном окружении проверок доступ к localhost/file URL заблокирован.
Публикацию GitHub Pages и реальную установку PWA нужно дополнительно проверить
после первой публикации в браузере телефона. Реальных серверных ключей нет.

Известные ограничения: не все сложные текстовые эффекты карт можно точно
просчитать автоматически; действия соперников и скрытые карты остаются
неизвестными. Сайт рассчитан на быстрые подсказки, **не на 100% гарантированную
победу**. Фотографии карт имеют ознакомительное назначение.

- Приложение даёт вероятностные рекомендации, а не гарантирует победу. Некоторые сложные свойства и фактические результаты бросков надо записывать по картам.
