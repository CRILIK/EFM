📲 Сайт на телефоне

На GitHub Pages сайт можно добавить на главный экран телефона. Чтобы фотографии всех карт были доступны без интернета, сохраните их один раз.

Проверка возможности сохранения…

Если кнопки установки нет, откройте меню браузера → «Добавить на главный экран». Локальный HTML можно открывать и без сервера, но установка на главный экран работает через HTTPS.
